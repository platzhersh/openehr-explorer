Usage Guidelines

✓ Do

  • Use #64ffda teal as the primary accent on dark (#1a1a2e+) backgrounds
  • Use Inter SemiBold for the wordmark at 14px minimum
  • Pair the logo with adequate clear space (minimum half the logo height on all sides)
  • Use JetBrains Mono for all code and path examples

✗ Don't

  • Use oehrpy's blue #3b82f6 or orange #f97316 — those colours are oehrpy's identity
  • Place teal #64ffda on white or light backgrounds (contrast fails WCAG AA)
  • Recreate the logo from memory — download the SVG when available
  • Modify the wordmark font, weight, or letter-spacing
